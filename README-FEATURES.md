## 🚀 How to Use

### For Courses:
1. **Browse All Courses**: Visit `/courses` to see all available courses
2. **Get Recommendations**: Upload your CV first, then click "Recommended for Me" tab
3. **Filter & Search**: Use filters to find courses by category, difficulty, or provider
4. **Enroll**: Click "View Course" to visit the course page and enroll

### For Enhanced Internships:
1. **Browse Opportunities**: Visit `/internships` to see all available positions
2. **View Details**: See salary, location, and remote options
3. **Apply Directly**: Click "Apply Now" to go to the application page
4. **Get Matches**: Use AI matching to find positions that fit your skills
